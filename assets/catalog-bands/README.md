# نوارهای کاتالوگ دریچه و منهول کامپوزیتی

منبعِ عکس محصول‌های خانواده‌های کامپوزیتی. هر فایل یک «نوار» از یک صفحه کاتالوگ سازنده است
که چند محصول کنار هم در آن نشسته‌اند.

فایل PDF اصلی کاتالوگ دیگر روی سیستم نیست؛ این نوارها از کامیت `1130d5f` بازیابی شده‌اند و
تنها منبع موجودند. پاکشان نکنید — بدون این‌ها عکس محصول‌ها قابل ساخت دوباره نیست.

ساخت عکس محصول‌ها از روی این‌ها:

```bash
npx tsx scripts/build-cover-images.ts
```

## نوار ناقص

`composite-manhole-covers-4.webp` خودش در همان کامیت بد بریده شده: نیمه پایین هر سه محصول
(درب ۶۳، ۶۴ و ۶۵) در فایل نیست. آن سه عکس تا وقتی صفحه اصلی کاتالوگ پیدا نشود بریده می‌مانند.
